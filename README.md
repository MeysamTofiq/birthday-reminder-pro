# یادآور تولد (Birthday Reminder Pro)

## معرفی (فارسی)

برنامه دسکتاپ ویندوزی که **تولدهای پرسنل و مشتریان** را مدیریت می‌کند — یک فایل **اکسل** حاوی نام و تاریخ تولد به آن می‌دهید و برنامه **سه روز قبل** از هر تولد به شما یادآوری می‌کند (با آیکون کنار ساعت/System Tray).

### ویژگی‌ها

- 🎂 ثبت تولدهای پرسنل و مشتریان از فایل اکسل
- 🔔 یادآوری سه روز قبل از تولد
- 📋 جدول مدیریت با جستجو، گروه‌بندی و فیلتر
- 📁 دسته‌بندی آدم‌ها (پرسنل/مشتری/سفارشی)
- 🖥 طراحی با Fluent Design (qfluentwidgets) و تقویم شمسی (jdatetime)
- 📍 آیکون System Tray برای اجرای دائمی در پس‌زمینه

### فناوری

Python · PyQt5 · qfluentwidgets · jdatetime · openpyxl · pystray

### اجرا

```bash
pip install PyQt5 qfluentwidgets jdatetime openpyxl pystray pillow
python birthday_app_pro3.py
```

# Birthday Reminder Pro

## Overview (English)

A Windows desktop app that tracks **employee & customer birthdays** — feed it an **Excel file** with names and birth dates, and it **reminds you 3 days before** each birthday (with a System-Tray icon so it keeps running in the background).

### Features

- 🎂 Import birthdays (employees/customers) from Excel
- 🔔 3-day advance reminder
- 📋 Manageable table with search, grouping and filters
- 📁 Contact categories (staff/customer/custom)
- 🖥 Fluent Design UI (qfluentwidgets) + Jalali calendar
- 📍 System Tray icon for background operation

### Tech Stack

Python · PyQt5 · qfluentwidgets · jdatetime · openpyxl · pystray

### Run

```bash
pip install PyQt5 qfluentwidgets jdatetime openpyxl pystray pillow
python birthday_app_pro3.py
```
